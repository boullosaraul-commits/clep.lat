# Programa CLEP 2027 · espacio de trabajo

Versión de trabajo v0.1 · 31 de octubre de 2026.

## Regla de separación

- `docs/`: deliberación, planificación y memoria del repositorio.
- `dist/`: información pública del sitio; las actividades sólo se anuncian como confirmadas con evidencia suficiente.

La raíz de despliegue declarada en README es `dist/`. No se enlazan estos documentos desde el sitio ni se incluyen en sitemap, metadatos de eventos o colas editoriales. Interno significa fuera de clep.lat: si GitHub es público, estos archivos son legibles allí; no constituyen un espacio confidencial.

## Actualización y trazabilidad

Editar mediante commits pequeños: indicar qué cambia y conservar las razones de cambios de estado. Usar ACORDADO / PROPUESTA / POR DECIDIR / DEPENDENCIA EXTERNA. En cada decisión registrar fecha, fundamento verificable y órgano o personas que deben decidir; no asignar nombres o cargos inexistentes. ACORDADO exige referencia a acta, minuta o decisión documentada; la instrucción de crear este espacio no acredita consenso de CLEP sobre el programa. Las decisiones sustituidas se conservan con referencia a la que las reemplaza.

Antes de publicar una actividad deben estar aprobados su alcance, responsables que acepten, calendario, modalidad y capacidad operativa; deben verificarse además sede o plataforma, condiciones de acceso, permisos y toda colaboración que se vaya a anunciar. Los datos pendientes no se rellenan por inferencia. Seguir [el procedimiento de publicación](publicacion.md).
